# Legacy Tally REST API (archived)

These modules are the retired legacy Tally REST endpoints (`send_tally.py` and
`receive_tally.py`). They are no longer installed or whitelisted and are kept
here only for historical reference.

The supported path is the flow framework / Control Centre. See the framework
endpoints documented in the root `README.md` and `docs/flow-framework.md`.

Archived on 2026-11-04.
